# JustShuo

Read and watch anything in Chinese: pinyin over every word, meanings at a click, flashcards, and twenty graded fairy
tales to start with.

**Download JustShuo and read about it at <https://laowaidave.github.io/JustShuo/>.**

Every version's files are on the [releases page](https://github.com/laowaidave/JustShuo/releases).
Installed copies of JustShuo update themselves from `update-1.json` here, which is signed by
Six Kingdoms Publishing; JustShuo checks the signature and each download's checksum before installing.
